## AudioWorklet note detection and latency without calibration

- Live note detection moved from the 45 ms analyser poll to an AudioWorklet (`inputWorklet.ts` around the pure `InputAnalyzer`), so it no longer competes with notation and playback on the main thread and attacks are stamped from the audio clock. - The analyzer uses two attack cues: the shared `TransientDetector` (the same one that grades recordings) for jumps in level, and a jump in brightness for a string re-picked while still ringing.
